## 1. 全体像

自分の講座を販売するための動画講座プラットフォームです。動画はYouTubeの埋め込みで配信します。

**動画1本が1つの講座です。** 管理者はタイトル、説明、YouTubeのURLを入力して保存し、公開します。受講者はログインすると、公開中の講座を一覧で見て視聴できます。

進め方は「まず教材どおりに完成させ、その後で実際に販売する」です。MVPに決済は入れません。

## 2. 決定事項の一覧

| 項目 | 決定内容 | 補足 |
|---|---|---|
| 目的 | 自分の講座を販売する | 講師は自分だけ |
| 決済 | MVPには含めない | 販売の準備段階で追加する |
| 講座の構成 | 動画1本で1つの講座 | セクションとレッスンは持たない |
| 管理画面の入力 | タイトル、説明、YouTubeのURL | 説明は未入力でも可。サムネイルの入力はなし |
| 見られる範囲 | すべてログイン後だけ | ログインした人は公開中の講座をすべて視聴できる |
| ログイン方法 | Googleログインのみ | |
| 管理者 | 自分だけ | 環境変数 `ADMIN_EMAIL` と比較して判定する |
| 動画の登録方法 | YouTubeのURLを貼り付ける | 対応形式は `youtube.com/watch?v=ID` と `youtu.be/ID` |
| 動画の公開設定 | すべて限定公開 | YouTube側で設定し、埋め込みも許可する |
| 再生できない場合 | YouTubeプレーヤーの表示に任せる | |
| 進捗 | 講座ごとの視聴済み | 自動の完了と「完了」ボタンの併用。押し直すと取り消せる |
| 公開状態 | 下書きと公開を切り替える | 新しい講座は下書き |
| 削除 | 確認ダイアログ付きで削除できる | 進捗も消える。元に戻せない |
| デプロイ先 | Vercel | |

## 4. MVPの機能

### 4.1 受講者向け（すべてログイン必須）

| 画面 | URL | 内容 |
|---|---|---|
| 講座一覧 | `/` | 公開中の講座、視聴済みの印、「2本中1本 視聴済み」の表示 |
| 講座の視聴 | `/courses/[courseId]` | タイトル、説明、YouTube動画、「完了」ボタン |

### 4.2 管理者向け

| 画面 | URL | 内容 |
|---|---|---|
| 管理画面 | `/admin` | 講座の作成、一覧 |
| 講座の編集 | `/admin/courses/[courseId]` | 修正、公開と下書きの切り替え、削除 |

### 4.3 共通

| 画面 | URL | 内容 |
|---|---|---|
| ログイン | `/login` | Googleでログイン |

### 4.4 MVPに含めないもの

- 決済、購入者だけが視聴できる仕組み
- セクション、レッスン、並び替え
- サムネイルの入力、アップロード
- 再生位置の記録、続きからの再開
- 複数の講師の参加
- メールとパスワードでのログイン
- 削除したデータの復元

## 5. 動作のルール

### 5.1 ログインと権限

- ログイン画面以外は、未ログインなら `/login` へ移動します。ログイン後は `/` へ戻ります。
- Googleで確認済みのメールアドレスが `ADMIN_EMAIL` と一致する人を管理者とします。
- 管理者以外が管理画面を開くと「ページが見つからない」表示にし、管理画面の存在を隠します。
- 権限は、画面とAPIの両方でサーバー側で確認します。

### 5.2 公開

- 受講者は `published` の講座だけを見られます。
- `draft` の講座は、ログイン済みの受講者にも404を返します。

### 5.3 進捗

- 動画が最後まで再生されたら、自動で視聴済みにします（YouTube IFrame Player API）。
- 「完了」ボタンでも視聴済みにでき、押し直すと取り消せます。
- 早送りやボタン操作でも視聴済みにできるので、視聴の証明にはなりません。

### 5.4 誤操作の防止

- 削除ボタンは保存ボタンから離し、確認ダイアログを挟みます。
- 通信中はボタンを押せないようにします。

## 6. データ設計

Better Authが使うテーブルに加えて、次のテーブルがあります。定義の正本は `src/db/course-schema.ts` です。

```text
courses（講座）
  id
  title              タイトル
  description        説明（任意）
  youtube_video_id   YouTubeの動画ID
  status             draft または published
  created_at
  updated_at
    │ 1対多（講座の削除時に一緒に削除）
    ▼
course_progress（進捗）
  user_id            誰の記録か（ユーザーの削除時に一緒に削除）
  course_id          どの講座か
  completed_at       完了した日時
  ※ user_id と course_id の組み合わせは重複させない
```

## 7. API

エラーは、すべて次の形式で返します。

```json
{ "error": { "code": "VALIDATION_ERROR", "message": "画面に表示できる説明" } }
```

| ステータス | `code` | 意味 |
|---|---|---|
| 400 | `VALIDATION_ERROR` | 入力が正しくない |
| 401 | `UNAUTHORIZED` | 未ログイン |
| 403 | `FORBIDDEN` | 管理者以外 |
| 404 | `NOT_FOUND` | 対象が存在しない |
| 500 | `INTERNAL_ERROR` | サーバー側の想定外のエラー |

### 7.1 管理用API（管理者専用）

| 操作 | メソッドとURL |
|---|---|
| 一覧 | `GET /api/admin/courses` |
| 作成 | `POST /api/admin/courses` |
| 取得 | `GET /api/admin/courses/[courseId]` |
| 修正 | `PATCH /api/admin/courses/[courseId]` |
| 削除 | `DELETE /api/admin/courses/[courseId]` |
| 公開 | `POST /api/admin/courses/[courseId]/publish` |
| 下書きに戻す | `POST /api/admin/courses/[courseId]/unpublish` |

作成と修正の入力は `title`、`description`、`youtubeUrl` です。公開状態は修正では変更できません。

### 7.2 進捗のAPI（ログイン必須）

| 操作 | メソッドとURL |
|---|---|
| 視聴済みにする | `PUT /api/courses/[courseId]/progress` |
| 取り消す | `DELETE /api/courses/[courseId]/progress` |

記録の対象はログイン中のユーザーだけです。下書きや存在しない講座は404を返します。

## 8. 必要な環境変数

`TURSO_DATABASE_URL`、`TURSO_AUTH_TOKEN`、`BETTER_AUTH_SECRET`、`BETTER_AUTH_URL`、`GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`ADMIN_EMAIL` です。見本は `.env.example` にあります。秘密の値はGitに含めません。

## 9. 実際に販売を始める前の確認事項

| 項目 | 確認すること |
|---|---|
| 決済 | 決済サービスの導入、購入履歴、購入者だけが視聴できる仕組み |
| 動画の保護 | ログイン後の画面では動画IDが見える。URLが広まると未購入の人も視聴できる可能性を、どこまで許容するか |
| 見せる範囲 | 購入前に一覧や説明を見せるため、ログイン前の公開を検討する |
| 再生エラーの案内 | 独自の案内メッセージを追加するか |
| Vercelのプラン | Hobbyプランは個人の非商用利用が対象。Proプランへの変更と最新の規約・料金を確認する |
| ログイン方法 | Googleアカウントがない人も受講者にするか |
| データの削除 | 購入履歴や進捗がある講座を消してよいか |
| サポートメール | 受講者に見える窓口を、個人のアドレスから変更する |
| 法律・規約 | 利用規約、プライバシーポリシー、特定商取引法に基づく表記などを確認する |
| セキュリティ | CSRF対策など、公開前のセキュリティ確認を行う |
